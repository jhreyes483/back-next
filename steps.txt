CONTEXTO
En drizzle las bases de datos se definen por medio de los schemas y con drizzel-kit se enlaza con la db
Migraciones
- comandos
generate, migrate, push, pull, export, check y studio
 - sintaxis
 npx drizzle-kit <comando>

(
    generate: genera archivos de migracion a partir de tu esquema
    migrate: ejecuta las migraciones generadas en la base de datos, mantine un historial de migraciones que ya se aolicarion
)

pull: Lee la estructura actual de la base de datos y genera un esquema de Drizzle apartir de ella. Util si la base de datos ya existe y se quiere inciar con drizzel 
export: Exporta el estado actual de la base de datos en un archivo SQL plano. Sirve para respaldos o para mover la estructura a otro entorno
check: Revisa si tu esquema en TypeScript y tu base de datos estan sincrinizados.
studio: abre una interfaz visual( Drizzle Studio) en el navegador para inspeccionar y gestionar la base de datos

Autenticacion: BETTER AUTH
Framework de autenticacion para TypeScript.
Es usado en difrentes Frameworks como next.js, Nuxt, Astro, Remix, SevelteKit, SolidStart o TanStak Start o Exppress.

Instalacion
npm i better-auth --force

Genera solo el schemas de better-auth
npx @better-auth/cli@latest generate
Se debe ralizar unos cambios espesificos

npx drizzle-kit generate
npx drizzle-kit migrate
